# Seção "Depoimentos" — Setembro Amarelo

Arquivos:
- `index.html` — estrutura da página.
- `style.css` — visual, responsividade e animações.
- `script.js` — carrossel, menu mobile e formulário demonstrativo.

## Como usar

Abra `index.html` no navegador. Os três arquivos devem ficar na mesma pasta.

### Integração ao site principal

A seção pode ser incorporada como um bloco da página principal. Os IDs usados são:
- `#inicio`
- `#depoimentos`
- `#compartilhar`
- `#ajuda`
- `#sobre`
- `#contato`

O formulário de depoimento é somente front-end/demonstração: ele não envia nem armazena dados.
Para um site real, conecte o formulário a um backend seguro e defina uma política de privacidade adequada.

O botão "CVV • 188" usa o telefone de apoio emocional do CVV.
